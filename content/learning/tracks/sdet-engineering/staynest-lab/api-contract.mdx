# StayNest - API Contract

**Base URL**: `http://localhost:8080/api/v1`

**Swagger UI**: `http://localhost:8080/api/v1/swagger-ui.html` (available when the backend is running)

All responses are wrapped in an `ApiResponse` envelope:
```json
{
  "timeStamp": "2024-01-15T10:30:00",
  "data": { ... },
  "error": null
}
```

---

## Authentication

Public endpoints -- no token required.

### POST /auth/signup

Create a new user account.

| Field | Details |
| ----- | ------- |
| **Auth** | None |
| **Request Body** | `{ "email": "user@example.com", "password": "pass123", "name": "John Doe", "roles": ["GUEST"] }` |
| **Required Fields** | `email` (valid format), `password` (min 6 chars), `name` (not blank) |
| **Optional Fields** | `roles` (defaults to `["GUEST"]` if omitted; can be `["HOTEL_MANAGER"]`) |
| **Success** | `201 Created` -- returns `UserDto { id, email, name, gender, dateOfBirth }` |
| **Errors** | `400` -- validation failure, `500` -- duplicate email |

### POST /auth/login

Authenticate and receive tokens.

| Field | Details |
| ----- | ------- |
| **Auth** | None |
| **Request Body** | `{ "email": "user@example.com", "password": "pass123" }` |
| **Success** | `200 OK` -- returns `{ "accessToken": "<jwt>" }`. Also sets `refreshToken` as HttpOnly cookie. |
| **Errors** | `401` -- invalid credentials |

**JWT claims in access token:**
- `sub` -- user ID (as string)
- `email` -- user email
- `roles` -- user roles (as string)
- `iat` -- issued at
- `exp` -- expires at (iat + 10 minutes)

### POST /auth/refresh

Refresh an expired access token.

| Field | Details |
| ----- | ------- |
| **Auth** | None (uses cookie) |
| **Required** | `refreshToken` cookie must be present |
| **Success** | `200 OK` -- returns `{ "accessToken": "<new-jwt>" }` |
| **Errors** | `401` -- missing or invalid refresh token |

## Hotel Browse (Public)

Search and view hotels. No authentication required.

### POST /hotels/search

Search for available hotels.

| Field | Details |
| ----- | ------- |
| **Auth** | None |
| **Request Body** | `{ "city": "New York", "startDate": "2025-03-01", "endDate": "2025-03-05", "roomsCount": 1, "page": 0, "size": 10 }` |
| **Required Fields** | `city` (not blank), `startDate` (today or future), `endDate` (today or future), `roomsCount` (min 1) |
| **Optional Fields** | `page` (default 0), `size` (default 10) |
| **Success** | `200 OK` -- returns paginated `Page<HotelPriceResponseDto>` |
| **Response Shape** | `{ "content": [{ "id", "name", "city", "photos", "amenities", "contactInfo", "active", "price" }], "totalElements", "totalPages", "number", "size" }` |
| **Errors** | `400` -- validation failure |

### GET /hotels/{'{'}hotelId{'}'}/info?startDate=...&endDate=...&roomsCount=...

Get detailed hotel info with room pricing for a date range.

| Field | Details |
| ----- | ------- |
| **Auth** | None |
| **Path Params** | `hotelId` (Long) |
| **Query Params** | `startDate` (LocalDate), `endDate` (LocalDate), `roomsCount` (Long) |
| **Success** | `200 OK` -- returns `HotelInfoDto` with hotel details and room pricing |
| **Errors** | `404` -- hotel not found |

| Field | Details |
| ----- | ------- |
| **Auth** | Bearer token (HOTEL_MANAGER) |
| **Request Body** | `{ "name": "Grand Hotel", "city": "New York", "photos": [...], "amenities": [...], "contactInfo": { "address": "...", "phoneNumber": "...", "email": "...", "location": "..." } }` |

## Bookings

All endpoints require authentication (any role). Prefix: `/bookings`.

### POST /bookings/init

Initiate a new booking (reserve rooms).

| Field | Details |
| ----- | ------- |
| **Auth** | Bearer token (any authenticated user) |
| **Request Body** | `{ "hotelId": 1, "roomId": 1, "checkInDate": "2025-03-01", "checkOutDate": "2025-03-05", "roomsCount": 1 }` |
| **Required Fields** | All fields required. `checkInDate` and `checkOutDate` must be today or future. `roomsCount` >= 1. |
| **Success** | `200 OK` -- returns `BookingDto` with status `RESERVED` |
| **Errors** | `400` -- validation, `404` -- hotel/room not found, `409` -- no inventory available |

### POST /bookings/{'{'}bookingId{'}'}/addGuests

Add guest IDs to a booking.

| Field | Details |
| ----- | ------- |
| **Auth** | Bearer token (must be booking owner) |
| **Request Body** | `[1, 2, 3]` (list of guest IDs) |
| **Success** | `200 OK` -- returns `BookingDto` with status `GUESTS_ADDED` |
| **Errors** | `404` -- booking/guest not found, `403` -- not owner, `409` -- not RESERVED status or expired |

### POST /bookings/{'{'}bookingId{'}'}/payments

Initiate payment for a booking.

| Field | Details |
| ----- | ------- |
| **Auth** | Bearer token (must be booking owner) |
| **Success** | `200 OK` -- returns `{ "sessionUrl": "<stripe-checkout-url-or-MOCK_PAYMENT_SUCCESS>" }` |
| **Errors** | `404` -- not found, `403` -- not owner, `409` -- expired |

**Mock mode**: When Stripe key is placeholder, returns `"MOCK_PAYMENT_SUCCESS"` and auto-confirms the booking.

### POST /bookings/{'{'}bookingId{'}'}/cancel

Cancel a confirmed booking.

| Field | Details |
| ----- | ------- |
| **Auth** | Bearer token (must be booking owner) |
| **Success** | `204 No Content` |
| **Errors** | `404` -- not found, `403` -- not owner, `409` -- not CONFIRMED status |

### GET /bookings/{'{'}bookingId{'}'}/status

Check booking status.

| Field | Details |
| ----- | ------- |
| **Auth** | Bearer token (must be booking owner) |
| **Success** | `200 OK` -- returns `{ "bookingStatus": "CONFIRMED" }` |
| **Errors** | `404` -- not found, `403` -- not owner |

## Webhook

### POST /webhook/payment

Stripe payment webhook endpoint.

| Field | Details |
| ----- | ------- |
| **Auth** | Stripe signature verification (not JWT) |
| **Request Body** | Raw Stripe event payload |

## Common HTTP Status Codes

| Code | Meaning                        | When It Happens                                     |
| ---- | ------------------------------ | --------------------------------------------------- |
| 200  | OK                             | Successful read or update                           |
| 201  | Created                        | Successful resource creation (signup, hotel, room, guest) |
| 204  | No Content                     | Successful delete, activate, profile update, cancel |
| 400  | Bad Request                    | Validation failure (missing/invalid fields)         |
| 401  | Unauthorized                   | Missing token, invalid token, wrong credentials     |
| 403  | Forbidden                      | Wrong role or accessing another user's resource      |
| 404  | Not Found                      | Resource does not exist                             |
| 409  | Conflict                       | Business rule violation (no inventory, wrong status) |
| 500  | Internal Server Error          | Unexpected error, duplicate email on signup          |
