## Project Description

Build a mobile test automation framework using Appium 2.x and Java for the StayNest Android and iOS apps. This project covers the unique challenges of mobile testing: device management, platform-specific locators, gesture automation, and cloud device grid integration with BrowserStack.

**What you'll build:** A framework that runs the same test logic on Android and iOS using shared screen objects, supports parallel device execution, handles mobile-specific interactions (swipe, scroll, tap-and-hold), and integrates with BrowserStack for cloud execution.

**System under test:** StayNest Android app (Kotlin + Jetpack Compose) and StayNest iOS app (SwiftUI)

### Milestone 1: Appium Setup and First Test (4 hours)

**Objectives:** Install Appium 2.x, configure an emulator, write a test that launches the app.

**Prerequisites:**
```bash
# Install Appium 2.x
npm install -g appium

# Install the UiAutomator2 driver (Android)
appium driver install uiautomator2

# Install the XCUITest driver (iOS — macOS only)
appium driver install xcuitest

# Verify installation
appium --version
appium driver list --installed
```


```java
// BaseMobileTest.java — foundation
public class BaseMobileTest {
    protected AppiumDriver driver;

    @BeforeMethod
    @Parameters({"platform"})
    public void setUp(@Optional("android") String platform) {
        driver = DriverFactory.createDriver(platform);
    }

    @AfterMethod
    public void tearDown() {
        if (driver != null) {
            driver.quit();
        }
    }
}

// DriverFactory.java
public class DriverFactory {
    public static AppiumDriver createDriver(String platform) {
        URL appiumUrl;
        try {
            appiumUrl = new URL(ConfigReader.get("appium.url")); // http://localhost:4723
        } catch (MalformedURLException e) {
            throw new RuntimeException("Invalid Appium URL", e);
        }

        return switch (platform.toLowerCase()) {
            case "android" -> createAndroidDriver(appiumUrl);
            case "ios" -> createIOSDriver(appiumUrl);
            default -> throw new IllegalArgumentException("Unknown platform: " + platform);
        };
    }

    private static AppiumDriver createAndroidDriver(URL url) {
        UiAutomator2Options options = new UiAutomator2Options()
            .setDeviceName(ConfigReader.get("android.device.name"))
            .setApp(ConfigReader.get("android.app.path"))
            .setAutomationName("UiAutomator2")
            .setAutoGrantPermissions(true)
            .setNewCommandTimeout(Duration.ofSeconds(60));
        return new AndroidDriver(url, options);
    }

    private static AppiumDriver createIOSDriver(URL url) {
        XCUITestOptions options = new XCUITestOptions()
            .setDeviceName(ConfigReader.get("ios.device.name"))
            .setApp(ConfigReader.get("ios.app.path"))
            .setAutomationName("XCUITest")
            .setAutoAcceptAlerts(true)
            .setNewCommandTimeout(Duration.ofSeconds(60));
        return new IOSDriver(url, options);
    }
}
```

**Success criteria:**
- [ ] Appium server starts without errors
- [ ] Test launches the StayNest app on an emulator/simulator
- [ ] App screenshot can be captured programmatically

### Milestone 2: Screen Objects (4 hours)

**Objectives:** Create screen objects for login and home screens with platform-specific locators.


```java
public class LoginScreen {
    private final AppiumDriver driver;
    private final WebDriverWait wait;

    public LoginScreen(AppiumDriver driver) {
        this.driver = driver;
        this.wait = new WebDriverWait(driver, Duration.ofSeconds(15));
    }

    // Platform-specific locator strategy
    private By emailField() {
        if (driver instanceof AndroidDriver) {
            return AppiumBy.accessibilityId("email_input");
        } else {
            return AppiumBy.accessibilityId("email_input"); // same if devs use matching IDs
        }
    }

    private By passwordField() {
        if (driver instanceof AndroidDriver) {
            return AppiumBy.accessibilityId("password_input");
        } else {
            return AppiumBy.accessibilityId("password_input");
        }
    }

    private By loginButton() {
        if (driver instanceof AndroidDriver) {
            return AppiumBy.accessibilityId("login_button");
        } else {
            return AppiumBy.accessibilityId("login_button");
        }
    }

    private By errorMessage() {
        return AppiumBy.accessibilityId("error_message");
    }

    public LoginScreen waitForScreen() {
        wait.until(ExpectedConditions.visibilityOfElementLocated(emailField()));
        return this;
    }

    public HomeScreen login(String email, String password) {
        WebElement emailEl = wait.until(
            ExpectedConditions.visibilityOfElementLocated(emailField()));
        emailEl.clear();
        emailEl.sendKeys(email);

        WebElement passEl = driver.findElement(passwordField());
        passEl.clear();
        passEl.sendKeys(password);

        // Hide keyboard if visible (common mobile issue)
        try { driver.hideKeyboard(); } catch (Exception ignored) {}

        driver.findElement(loginButton()).click();
        return new HomeScreen(driver);
    }

    public String getErrorMessage() {
        WebElement error = wait.until(
            ExpectedConditions.visibilityOfElementLocated(errorMessage()));
        return error.getText();
    }
}
```

**Success criteria:**
- [ ] LoginScreen and HomeScreen objects encapsulate all locators
- [ ] Login test passes using screen objects
- [ ] Keyboard hiding is handled (Android-specific behavior)

### Milestone 3: Gesture Utilities (4 hours)

**Objectives:** Build a reusable gesture helper for swipe, scroll, and long press.


```java
public class GestureHelper {
    private final AppiumDriver driver;

    public GestureHelper(AppiumDriver driver) {
        this.driver = driver;
    }

    /**
     * Swipe from bottom to top (scroll down to reveal more content).
     */
    public void swipeUp() {
        Dimension size = driver.manage().window().getSize();
        int startX = size.width / 2;
        int startY = (int) (size.height * 0.8);
        int endY = (int) (size.height * 0.2);

        PointerInput finger = new PointerInput(PointerInput.Kind.TOUCH, "finger");
        Sequence swipe = new Sequence(finger, 1);
        swipe.addAction(finger.createPointerMove(Duration.ZERO,
            PointerInput.Origin.viewport(), startX, startY));
        swipe.addAction(finger.createPointerDown(PointerInput.MouseButton.LEFT.asArg()));
        swipe.addAction(finger.createPointerMove(Duration.ofMillis(800),
            PointerInput.Origin.viewport(), startX, endY));
        swipe.addAction(finger.createPointerUp(PointerInput.MouseButton.LEFT.asArg()));
        driver.perform(List.of(swipe));
    }

    /**
     * Scroll down until an element is visible or max attempts reached.
     */
    public WebElement scrollToElement(By locator, int maxSwipes) {
        for (int i = 0; i < maxSwipes; i++) {
            try {
                WebElement element = driver.findElement(locator);
                if (element.isDisplayed()) return element;
            } catch (NoSuchElementException ignored) {}
            swipeUp();
        }
        throw new NoSuchElementException(
            "Element not found after " + maxSwipes + " swipes: " + locator);
    }

    /**
     * Pull to refresh (swipe down from top).
     */
    public void pullToRefresh() {
        Dimension size = driver.manage().window().getSize();
        int startX = size.width / 2;
        int startY = (int) (size.height * 0.3);
        int endY = (int) (size.height * 0.8);

        PointerInput finger = new PointerInput(PointerInput.Kind.TOUCH, "finger");
        Sequence pull = new Sequence(finger, 1);
        pull.addAction(finger.createPointerMove(Duration.ZERO,
            PointerInput.Origin.viewport(), startX, startY));
        pull.addAction(finger.createPointerDown(PointerInput.MouseButton.LEFT.asArg()));
        pull.addAction(finger.createPointerMove(Duration.ofMillis(600),
            PointerInput.Origin.viewport(), startX, endY));
        pull.addAction(finger.createPointerUp(PointerInput.MouseButton.LEFT.asArg()));
        driver.perform(List.of(pull));
    }
}
```

**Success criteria:**
- [ ] Swipe up, swipe down, and pull-to-refresh work on both platforms
- [ ] `scrollToElement` finds elements below the fold
- [ ] Gestures are reusable from any screen object

### Milestone 5: Parallel Device Execution (3 hours)

**Objectives:** Run tests simultaneously on multiple devices, thread-safe driver management.


```java
// Thread-safe driver management for parallel device execution
public class DriverManager {
    private static final ThreadLocal<AppiumDriver> driverThreadLocal = new ThreadLocal<>();

    public static AppiumDriver getDriver() {
        return driverThreadLocal.get();
    }

    public static void setDriver(AppiumDriver driver) {
        driverThreadLocal.set(driver);
    }

    public static void quitDriver() {
        AppiumDriver driver = driverThreadLocal.get();
        if (driver != null) {
            driver.quit();
            driverThreadLocal.remove();
        }
    }
}
```

**Success criteria:**
- [ ] 2 devices run tests simultaneously (locally or via BrowserStack)
- [ ] No driver conflicts between threads
- [ ] Each test gets its own driver instance

### Milestone 6: CI Integration (3 hours)

**Objectives:** Jenkins or GitHub Actions pipeline that runs mobile tests against BrowserStack.


```yaml
# .github/workflows/mobile-tests.yml
name: Mobile Tests
on: [push]
jobs:
  mobile-test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-java@v4
        with:
          java-version: '21'
          distribution: 'temurin'
      - name: Upload app to BrowserStack
        run: |
          curl -u "${{ secrets.BS_USERNAME }}:${{ secrets.BS_ACCESS_KEY }}" \
            -X POST "https://api-cloud.browserstack.com/app-automate/upload" \
            -F "file=@app/staynest.apk" > bs_app.json
          echo "APP_URL=$(jq -r .app_url bs_app.json)" >> $GITHUB_ENV
      - name: Run tests
        run: mvn test -DsuiteXmlFile=testng-browserstack.xml
        env:
          BROWSERSTACK_USERNAME: ${{ secrets.BS_USERNAME }}
          BROWSERSTACK_ACCESS_KEY: ${{ secrets.BS_ACCESS_KEY }}
          BROWSERSTACK_APP_URL: ${{ env.APP_URL }}
```

## Mobile-Specific Challenges and Solutions

| Challenge | Solution |
| --- | --- |
| Different locators per platform | Method-based locator strategy (`emailField()` returns platform-specific By) |
| Keyboard covers input fields | `driver.hideKeyboard()` after typing, or scroll element into view first |
| Elements below the fold | `GestureHelper.scrollToElement()` with max swipes |
| Slow element rendering | Longer explicit waits (15s default for mobile vs 10s for web) |
| App state persistence | `driver.resetApp()` or `driver.terminateApp()` + `driver.activateApp()` between tests |
| Network dependency | API test data setup ensures backend state is correct before mobile tests |
