### A1: Validate Email Format

**Problem:** Write a method `boolean isValidEmail(String email)` that returns `true` if the email:
- Contains exactly one `@`
- Has at least one `.` after the `@`
- Contains no spaces
- Is not null or empty

**Input/Output Examples:**

| Input | Output | Reason |
|---|---|---|
| `"test@email.com"` | `true` | Valid format |
| `"user@domain.co.uk"` | `true` | Multiple dots after `@` are fine |
| `"test@.com"` | `true` | Has `@` and `.` after it (this is a simple validator, not RFC-compliant) |
| `"testmail.com"` | `false` | No `@` |
| `"test@@email.com"` | `false` | Two `@` symbols |
| `"test @email.com"` | `false` | Contains space |
| `null` | `false` | Null input |
| `""` | `false` | Empty input |

**Constraints:** Do NOT use regex. Use `String` methods only (`indexOf`, `lastIndexOf`, `contains`, `charAt`, `length`, `substring`).

**Time Target:** 15 minutes

**Hints:**


**Hint 1 (direction)**

Handle null and empty first — they're your guard clauses. Then think about what `indexOf('@')` and `lastIndexOf('@')` being equal tells you.




**Hint 2 (approach)**

After confirming exactly one `@`, use `substring` to get the part after `@`, then check if that substring `contains(".")`. For spaces, `contains(" ")` works.




**Hint 3 (near-solution)**

```
1. if email is null or empty → return false
2. if email contains " " → return false
3. find index of '@' and lastIndex of '@' — if different, return false
4. if atIndex is -1 → return false
5. get afterAt = email.substring(atIndex + 1)
6. return afterAt.contains(".")
```



**Tests to Pass:**


```java
import org.junit.jupiter.api.Test;
import static org.junit.jupiter.api.Assertions.*;

class EmailValidatorTest {

    @Test
    void validEmailReturnsTrue() {
        assertTrue(isValidEmail("test@email.com"));
    }

    @Test
    void multiplDotsAfterAtReturnsTrue() {
        assertTrue(isValidEmail("user@domain.co.uk"));
    }

    @Test
    void missingAtReturnsFalse() {
        assertFalse(isValidEmail("testmail.com"));
    }

    @Test
    void doubleAtReturnsFalse() {
        assertFalse(isValidEmail("test@@email.com"));
    }

    @Test
    void nullInputReturnsFalse() {
        assertFalse(isValidEmail(null));
    }
}
```

**Solution:**


**Click to reveal solution**


```java
public static boolean isValidEmail(String email) {
    if (email == null || email.isEmpty()) {
        return false;
    }

    if (email.contains(" ")) {
        return false;
    }

    int atIndex = email.indexOf('@');
    int lastAtIndex = email.lastIndexOf('@');

    if (atIndex == -1 || atIndex != lastAtIndex) {
        return false;
    }

    String afterAt = email.substring(atIndex + 1);
    return afterAt.contains(".");
}
```



**Extension:** Write a method `List<String> filterValidEmails(List<String> emails)` that returns only the valid emails from the list using streams.


**Extension solution**


```java
public static List<String> filterValidEmails(List<String> emails) {
    if (emails == null) {
        return List.of();
    }
    return emails.stream()
            .filter(EmailValidator::isValidEmail)
            .collect(Collectors.toList());
}
```

### A2: Count Word Frequencies

**Problem:** Write a method `Map<String, Integer> countWords(String sentence)` that counts the occurrences of each word in the sentence. Words are case-insensitive (treat `"Hello"` and `"hello"` as the same word). Return an empty map for null or empty input.

**Input/Output Examples:**

| Input | Output |
|---|---|
| `"the cat sat on the mat"` | `{the=2, cat=1, sat=1, on=1, mat=1}` |
| `"Hello hello HELLO"` | `{hello=3}` |
| `""` | `{}` |
| `null` | `{}` |

**Constraints:** Use `String.split()` to tokenize. Use a `HashMap` for counting.

**Time Target:** 15 minutes

**Hints:**


**Hint 1 (direction)**

`split("\\s+")` splits on one or more whitespace characters — this handles multiple spaces between words.




**Hint 2 (approach)**

Convert the sentence to lowercase first, then split. For each word, use `map.getOrDefault(word, 0) + 1` to increment the count.




**Hint 3 (near-solution)**

```
1. Guard clause for null/empty
2. sentence = sentence.toLowerCase().trim()
3. Split on "\\s+"
4. For each word: map.put(word, map.getOrDefault(word, 0) + 1)
5. Return map
```



**Tests to Pass:**


```java

        assertEquals(2, result.get("the"));
        assertEquals(1, result.get("cat"));
    }

    @Test
    void caseInsensitive() {
        Map<String, Integer> result = countWords("Hello hello HELLO");
        assertEquals(3, result.get("hello"));
        assertEquals(1, result.size());
    }

    @Test
    void nullReturnsEmptyMap() {
        assertTrue(countWords(null).isEmpty());
    }

    @Test
    void emptyStringReturnsEmptyMap() {
        assertTrue(countWords("").isEmpty());
    }

    @Test
    void singleWord() {
        Map<String, Integer> result = countWords("java");
        assertEquals(1, result.get("java"));
    }
}
```

**Solution:**


**Click to reveal solution**


```java
public static Map<String, Integer> countWords(String sentence) {
    if (sentence == null || sentence.trim().isEmpty()) {
        return new HashMap<>();
    }

    String[] words = sentence.toLowerCase().trim().split("\\s+");
    Map<String, Integer> counts = new HashMap<>();

    for (String word : words) {
        counts.put(word, counts.getOrDefault(word, 0) + 1);
    }

    return counts;
}
```



**Extension:** Write `Map<String, Integer> duplicatesOnly(String sentence)` that returns only words appearing more than once.


**Extension solution**


```java
public static Map<String, Integer> duplicatesOnly(String sentence) {
    return countWords(sentence).entrySet().stream()
            .filter(entry -> entry.getValue() > 1)
            .collect(Collectors.toMap(Map.Entry::getKey, Map.Entry::getValue));
}
```

### A3: FizzBuzz Classifier

**Problem:** This is NOT classic "print FizzBuzz." Write two methods:

1. `String classify(int n)` — returns `"Fizz"` if `n` is divisible by 3, `"Buzz"` if divisible by 5, `"FizzBuzz"` if divisible by both, or the number as a string otherwise.
2. `List<String> classifyRange(int from, int to)` — applies `classify` to every integer in the inclusive range `[from, to]` and returns the results as a list.

**Input/Output Examples:**

| Input | Output |
|---|---|
| `classify(3)` | `"Fizz"` |
| `classify(5)` | `"Buzz"` |
| `classify(15)` | `"FizzBuzz"` |
| `classify(7)` | `"7"` |
| `classifyRange(1, 5)` | `["1", "2", "Fizz", "4", "Buzz"]` |

**Time Target:** 15 minutes

**Hints:**


**Hint 1 (direction)**

Order matters: check divisibility by both 3 AND 5 *first*, because a number divisible by both would also match the individual checks.




**Hint 2 (approach)**

Use `n % 3 == 0` and `n % 5 == 0`. For `classifyRange`, an `IntStream.rangeClosed(from, to)` with `.mapToObj()` is the stream approach; a simple for-loop works too.




**Hint 3 (near-solution)**

```
classify(n):
  if n % 15 == 0 → "FizzBuzz"    (or: n % 3 == 0 && n % 5 == 0)
  if n % 3 == 0  → "Fizz"
  if n % 5 == 0  → "Buzz"
  else           → String.valueOf(n)

classifyRange(from, to):
  List<String> results = new ArrayList<>();
  for (int i = from; i <= to; i++) results.add(classify(i));
  return results;
```



**Tests to Pass:**


```java

import java.util.List;
import static org.junit.jupiter.api.Assertions.*;

class FizzBuzzClassifierTest {

    @Test
    void divisibleByThreeReturnsFizz() {
        assertEquals("Fizz", classify(9));
    }

    @Test
    void divisibleByFiveReturnsBuzz() {
        assertEquals("Buzz", classify(10));
    }

    @Test
    void divisibleByBothReturnsFizzBuzz() {
        assertEquals("FizzBuzz", classify(30));
    }

    @Test
    void notDivisibleReturnsNumberAsString() {
        assertEquals("7", classify(7));
    }

    @Test
    void classifyRangeReturnsCorrectList() {
        List<String> expected = List.of("1", "2", "Fizz", "4", "Buzz");
        assertEquals(expected, classifyRange(1, 5));
    }
}
```

**Solution:**


**Click to reveal solution**


```java
public static String classify(int n) {
    if (n % 3 == 0 && n % 5 == 0) {
        return "FizzBuzz";
    } else if (n % 3 == 0) {
        return "Fizz";
    } else if (n % 5 == 0) {
        return "Buzz";
    } else {
        return String.valueOf(n);
    }
}

public static List<String> classifyRange(int from, int to) {
    List<String> results = new ArrayList<>();
    for (int i = from; i <= to; i++) {
        results.add(classify(i));
    }
    return results;
}
```

### B1: Find Duplicate Test Case Names

**Problem:** Write a method `Set<String> findDuplicates(List<String> testNames)` that returns a set of test case names that appear more than once in the list. Comparison should be case-sensitive. Return an empty set for null or empty input.

**Input/Output Examples:**

| Input | Output |
|---|---|
| `["loginTest", "logoutTest", "loginTest", "searchTest"]` | `{"loginTest"}` |
| `["a", "b", "c"]` | `{}` |
| `["x", "x", "x"]` | `{"x"}` |
| `null` | `{}` |

**Time Target:** 20 minutes

**Hints:**


**Hint 1 (direction)**

A `Set` rejects duplicates — `set.add(item)` returns `false` if the item already exists. You can use this return value to detect duplicates.




**Hint 2 (approach)**

Use two sets: one `seen` set to track all names encountered, and one `duplicates` set to collect names that fail the `seen.add()` check.




**Hint 3 (near-solution)**

```
Set<String> seen = new HashSet<>();
Set<String> duplicates = new HashSet<>();
for (String name : testNames) {
    if (!seen.add(name)) {
        duplicates.add(name);
    }
}
return duplicates;
```



**Tests to Pass:**


```java

    }

    @Test
    void tripleOccurrenceStillReturnedOnce() {
        Set<String> result = findDuplicates(List.of("x", "x", "x"));
        assertEquals(1, result.size());
        assertTrue(result.contains("x"));
    }

    @Test
    void nullReturnsEmptySet() {
        assertTrue(findDuplicates(null).isEmpty());
    }

    @Test
    void caseSensitive() {
        Set<String> result = findDuplicates(List.of("Login", "login"));
        assertTrue(result.isEmpty());
    }

```

**Solution:**


**Click to reveal solution**


```java
public static Set<String> findDuplicates(List<String> testNames) {
    if (testNames == null || testNames.isEmpty()) {
        return new HashSet<>();
    }

    Set<String> seen = new HashSet<>();
    Set<String> duplicates = new HashSet<>();

    for (String name : testNames) {
        if (!seen.add(name)) {
            duplicates.add(name);
        }
    }

    return duplicates;
}
```



**Extension:** Write `Map<String, Long> countOccurrences(List<String> testNames)` using streams and `Collectors.groupingBy` with `Collectors.counting()`.


**Extension solution**


```java
public static Map<String, Long> countOccurrences(List<String> testNames) {
    if (testNames == null) {
        return Map.of();
    }
    return testNames.stream()
            .collect(Collectors.groupingBy(Function.identity(), Collectors.counting()));
}
```

### B2: Group Test Results by Status

**Problem:** Given a list of test results, group the test names by their status.

First, define this record (or class):


```java
record TestResult(String name, String status, long durationMs) {}
```

Then write `Map<String, List<String>> groupByStatus(List<TestResult> results)` that returns a map where the key is the status (`"PASSED"`, `"FAILED"`, `"SKIPPED"`) and the value is a list of test names with that status.

**Input/Output Examples:**

| Input | Output |
|---|---|
| `[TestResult("login", "PASSED", 120), TestResult("checkout", "FAILED", 500), TestResult("search", "PASSED", 80)]` | `{PASSED=[login, search], FAILED=[checkout]}` |
| `[]` | `{}` |

**Time Target:** 20 minutes

**Hints:**


**Hint 1 (direction)**

You need a `Map<String, List<String>>`. For each result, get the list for that status (creating it if it doesn't exist), then add the test name to that list.




**Hint 2 (approach)**

`map.computeIfAbsent(status, k -> new ArrayList<>()).add(name)` is the cleanest imperative approach. It creates the list if the key is missing, then appends to it.




**Hint 3 (near-solution)**

Stream approach: `results.stream().collect(Collectors.groupingBy(TestResult::status, Collectors.mapping(TestResult::name, Collectors.toList())))`.



**Tests to Pass:**


```java
import org.junit.jupiter.api.Test;
import java.util.List;
import java.util.Map;
import static org.junit.jupiter.api.Assertions.*;

class TestResultGrouperTest {

    @Test
    void groupsByStatus() {
        List<TestResult> results = List.of(
            new TestResult("login", "PASSED", 120),
            new TestResult("checkout", "FAILED", 500),
            new TestResult("search", "PASSED", 80)
        );
        Map<String, List<String>> grouped = groupByStatus(results);
        assertEquals(List.of("login", "search"), grouped.get("PASSED"));
        assertEquals(List.of("checkout"), grouped.get("FAILED"));
    }

    @Test
    void emptyInputReturnsEmptyMap() {
        assertTrue(groupByStatus(List.of()).isEmpty());
    }

    @Test
    void allSameStatus() {
        List<TestResult> results = List.of(
            new TestResult("a", "PASSED", 10),
            new TestResult("b", "PASSED", 20)
        );
        Map<String, List<String>> grouped = groupByStatus(results);
        assertEquals(1, grouped.size());
        assertEquals(2, grouped.get("PASSED").size());
    }

    @Test
    void nullReturnsEmptyMap() {
        assertTrue(groupByStatus(null).isEmpty());
    }

    @Test
    void skippedTestsGrouped() {
        List<TestResult> results = List.of(
            new TestResult("flaky", "SKIPPED", 0)
        );
        assertEquals(List.of("flaky"), groupByStatus(results).get("SKIPPED"));
    }
}
```

**Solution:**


**Click to reveal solution — imperative**


```java
public static Map<String, List<String>> groupByStatus(List<TestResult> results) {
    if (results == null || results.isEmpty()) {
        return new HashMap<>();
    }

    Map<String, List<String>> grouped = new HashMap<>();
    for (TestResult result : results) {
        grouped.computeIfAbsent(result.status(), k -> new ArrayList<>())
               .add(result.name());
    }
    return grouped;
}
```




**Click to reveal solution — streams**


```java
public static Map<String, List<String>> groupByStatus(List<TestResult> results) {
    if (results == null || results.isEmpty()) {
        return Map.of();
    }
    return results.stream()
            .collect(Collectors.groupingBy(
                TestResult::status,
                Collectors.mapping(TestResult::name, Collectors.toList())
            ));
}
```

### B3: Merge Two Sorted Lists

**Problem:** Write `List<Integer> mergeSorted(List<Integer> list1, List<Integer> list2)` that merges two already-sorted lists into a single sorted list. Do NOT use `Collections.sort()` or `Stream.sorted()`. If either list is null, treat it as empty.

**Input/Output Examples:**

| Input | Output |
|---|---|
| `[1, 3, 5]`, `[2, 4, 6]` | `[1, 2, 3, 4, 5, 6]` |
| `[1, 1, 3]`, `[1, 2]` | `[1, 1, 1, 2, 3]` |
| `[]`, `[1, 2]` | `[1, 2]` |
| `null`, `[5]` | `[5]` |

**Time Target:** 20 minutes

**Hints:**


**Hint 1 (direction)**

Use two pointers, one for each list. Compare the elements at each pointer, add the smaller one, and advance that pointer.




**Hint 2 (approach)**

Loop while both pointers are within bounds. After the loop, one list may have remaining elements — append all of them.




**Hint 3 (near-solution)**

```
int i = 0, j = 0;
while (i < list1.size() && j < list2.size()) {
    if (list1.get(i) <= list2.get(j)) {
        result.add(list1.get(i++));
    } else {
        result.add(list2.get(j++));
    }
}
// Add remaining from whichever list isn't exhausted
while (i < list1.size()) result.add(list1.get(i++));
while (j < list2.size()) result.add(list2.get(j++));
```



**Tests to Pass:**

```java
    }

    @Test

        assertEquals(List.of(1, 2), mergeSorted(List.of(), List.of(1, 2)));
    }

    @Test
    void nullTreatedAsEmpty() {
        assertEquals(List.of(5), mergeSorted(null, List.of(5)));
    }

        assertTrue(mergeSorted(List.of(), List.of()).isEmpty());

}
```

**Solution:**


**Click to reveal solution**


```java
public static List<Integer> mergeSorted(List<Integer> list1, List<Integer> list2) {
    List<Integer> a = (list1 != null) ? list1 : List.of();
    List<Integer> b = (list2 != null) ? list2 : List.of();

    List<Integer> result = new ArrayList<>(a.size() + b.size());
    int i = 0, j = 0;

    while (i < a.size() && j < b.size()) {
        if (a.get(i) <= b.get(j)) {
            result.add(a.get(i++));
        } else {
            result.add(b.get(j++));
        }
    }

    while (i < a.size()) {
        result.add(a.get(i++));
    }
    while (j < b.size()) {
        result.add(b.get(j++));
    }

    return result;
}
```

### C1: Two Sum

**Problem:** Given an array of integers `nums` and an integer `target`, return the indices of the two numbers that add up to `target`. Assume exactly one solution exists, and you may not use the same element twice.

**Input/Output Examples:**

| Input | Output |
|---|---|
| `nums = [2, 7, 11, 15]`, `target = 9` | `[0, 1]` |
| `nums = [3, 2, 4]`, `target = 6` | `[1, 2]` |
| `nums = [3, 3]`, `target = 6` | `[0, 1]` |

**Complexity Target:** O(n) time, O(n) space

**Time Target:** 30 minutes (brute force first, then optimize)

**Hints:**


**Hint 1 (brute force)**

Two nested loops: for each element, check every other element to see if they sum to the target. This is O(n²) — correct but slow.




**Hint 2 (optimization direction)**

If you know one number, the other must be `target - number`. A `HashMap` lets you check "have I seen `target - number` before?" in O(1).




**Hint 3 (near-solution)**

```
Map<Integer, Integer> seen = new HashMap<>();  // value → index
for (int i = 0; i < nums.length; i++) {
    int complement = target - nums[i];
    if (seen.containsKey(complement)) {
        return new int[] { seen.get(complement), i };
    }
    seen.put(nums[i], i);
}
```



**Tests to Pass:**


```java
import org.junit.jupiter.api.Test;
import static org.junit.jupiter.api.Assertions.*;

class TwoSumTest {

    @Test
    void basicCase() {
        assertArrayEquals(new int[]{0, 1}, twoSum(new int[]{2, 7, 11, 15}, 9));
    }

    @Test
    void nonAdjacentElements() {
        assertArrayEquals(new int[]{1, 2}, twoSum(new int[]{3, 2, 4}, 6));
    }

    @Test
    void duplicateValues() {
        assertArrayEquals(new int[]{0, 1}, twoSum(new int[]{3, 3}, 6));
    }

    @Test
    void negativeNumbers() {
        assertArrayEquals(new int[]{0, 2}, twoSum(new int[]{-1, 0, 1}, 0));
    }

    @Test
    void largerArray() {
        assertArrayEquals(new int[]{2, 4}, twoSum(new int[]{1, 5, 3, 7, 3}, 6));
    }
}
```

**Solution:**


**Click to reveal solution — brute force O(n²)**


```java
public static int[] twoSumBrute(int[] nums, int target) {
    for (int i = 0; i < nums.length; i++) {
        for (int j = i + 1; j < nums.length; j++) {
            if (nums[i] + nums[j] == target) {
                return new int[]{i, j};
            }
        }
    }
    throw new IllegalArgumentException("No two sum solution");
}
```




**Click to reveal solution — optimal O(n)**


```java
public static int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> seen = new HashMap<>();

    for (int i = 0; i < nums.length; i++) {
        int complement = target - nums[i];
        if (seen.containsKey(complement)) {
            return new int[]{seen.get(complement), i};
        }
        seen.put(nums[i], i);
    }

    throw new IllegalArgumentException("No two sum solution");
}
```

### C2: Valid Parentheses

**Problem:** Given a string containing only the characters `(`, `)`, `{`, `}`, `[`, `]`, determine if the input string is valid. A string is valid if:
- Every open bracket is closed by the same type of bracket
- Brackets are closed in the correct order
- Every close bracket has a corresponding open bracket

**Input/Output Examples:**

| Input | Output |
|---|---|
| `"()"` | `true` |
| `"()[]{}"` | `true` |
| `"(]"` | `false` |
| `"([)]"` | `false` |
| `"{[]}"` | `true` |
| `""` | `true` |

**Complexity Target:** O(n) time, O(n) space

**Time Target:** 30 minutes

**Hints:**


**Hint 1 (direction)**

This is a classic stack problem. When you see an opening bracket, push it. When you see a closing bracket, pop and check if it matches.




**Hint 2 (approach)**

Use a `Deque<Character>` as a stack (`ArrayDeque` is the recommended implementation). Map each closing bracket to its expected opening bracket using a `Map`.




**Hint 3 (near-solution)**

```
1. Create a map: ')' → '(', ']' → '[', '}' → '{'
2. For each char in string:
   - If it's an opening bracket → push onto stack
   - If it's a closing bracket → if stack is empty or top doesn't match → return false; else pop
3. Return stack.isEmpty()  (handles unclosed brackets)
```

```java
public static boolean isValid(String s) {
    if (s == null) {
        return false;
    }

    Deque<Character> stack = new ArrayDeque<>();
    Map<Character, Character> pairs = Map.of(')', '(', ']', '[', '}', '{');

    for (char c : s.toCharArray()) {
        if (pairs.containsValue(c)) {
            stack.push(c);
        } else if (pairs.containsKey(c)) {
            if (stack.isEmpty() || !stack.pop().equals(pairs.get(c))) {
                return false;
            }
        }
    }

    return stack.isEmpty();
}
```

### C3: Longest Substring Without Repeating Characters

**Problem:** Given a string `s`, find the length of the longest substring without repeating characters.

**Input/Output Examples:**

| Input | Output | Explanation |
|---|---|---|
| `"abcabcbb"` | `3` | `"abc"` |
| `"bbbbb"` | `1` | `"b"` |
| `"pwwkew"` | `3` | `"wke"` |
| `""` | `0` | Empty string |

**Complexity Target:** O(n) using sliding window

**Time Target:** 30 minutes

**Hints:**


**Hint 1 (direction)**

Use a "sliding window" — two pointers (`left` and `right`) that define the current substring. Expand `right` to include new characters; shrink from `left` when you find a duplicate.




**Hint 2 (approach)**

Use a `Set<Character>` to track which characters are in the current window. When `right` finds a character already in the set, remove characters from `left` until the duplicate is gone.




**Hint 3 (near-solution)**

```
Set<Character> window = new HashSet<>();
int left = 0, maxLen = 0;
for (int right = 0; right < s.length(); right++) {
    while (window.contains(s.charAt(right))) {
        window.remove(s.charAt(left));
        left++;
    }
    window.add(s.charAt(right));
    maxLen = Math.max(maxLen, right - left + 1);
}
return maxLen;
```

### D1: Parse Configuration from Properties Format

**Problem:** Write `Map<String, String> parseProperties(List<String> lines)` that parses lines in `key=value` format into a map.

Handle these cases:
- **Comment lines** (starting with `#`) — skip them
- **Blank lines** — skip them
- **Keys with no value** (e.g., `debug=`) — store as empty string
- **Values containing `=`** (e.g., `url=https://api.com?a=1`) — only split on the *first* `=`
- **Leading/trailing whitespace** on keys and values — trim it

**Input/Output Examples:**

| Input Lines | Output |
|---|---|
| `["# DB config", "host=localhost", "port=5432", "", "debug=", "url=https://x.com?a=1"]` | `{host=localhost, port=5432, debug=, url=https://x.com?a=1}` |

**Hint 3 (near-solution)**

```
    String value = trimmed.substring(eqIndex + 1).trim();
```

```java
public static Map<String, String> parseProperties(List<String> lines) {
    if (lines == null) {
        return new HashMap<>();
    }

    Map<String, String> properties = new LinkedHashMap<>();

    for (String line : lines) {
        String trimmed = line.trim();

        if (trimmed.isEmpty() || trimmed.startsWith("#")) {
            continue;
        }

        int eqIndex = trimmed.indexOf('=');
        if (eqIndex == -1) {
            continue;
        }

        String key = trimmed.substring(0, eqIndex).trim();
        String value = trimmed.substring(eqIndex + 1).trim();
        properties.put(key, value);
    }

    return properties;
}
```

**Problem:** Write `List<String> validateBookingResponse(Map<String, Object> response)` that validates a booking API response and returns a list of validation error messages. An empty list means the response is valid.

Validation rules:
1. Must have key `"id"` — value must be a positive `Integer`

3. Must have key `"checkInDate"` and `"checkOutDate"` — both must be `String` in any format, but `checkInDate` must come before `checkOutDate` lexicographically (assumes ISO format like `"2024-01-15"`)
4. Must have key `"amount"` — value must be a positive `Number`

|---|---|

**Hint 1 (direction)**

**Hint 3 (near-solution)**

```java
public static List<String> validateBookingResponse(Map<String, Object> response) {
    List<String> errors = new ArrayList<>();

    if (response == null) {
        return List.of("Response is null");
    }

    // Validate id
    Object id = response.get("id");
    if (id == null) {
        errors.add("id is required");
    } else if (!(id instanceof Integer) || (Integer) id <= 0) {
        errors.add("id must be a positive integer");
    }

    // Validate status
    Set<String> validStatuses = Set.of("RESERVED", "CONFIRMED", "CANCELLED");
    Object status = response.get("status");
    if (status == null) {
        errors.add("status is required");
    } else if (!(status instanceof String) || !validStatuses.contains(status)) {
        errors.add("status must be one of [RESERVED, CONFIRMED, CANCELLED]");
    }

    // Validate dates
    Object checkIn = response.get("checkInDate");
    Object checkOut = response.get("checkOutDate");

    if (checkIn == null) {
        errors.add("checkInDate is required");
    }
    if (checkOut == null) {
        errors.add("checkOutDate is required");
    }
    if (checkIn instanceof String checkInStr && checkOut instanceof String checkOutStr) {
        if (checkInStr.compareTo(checkOutStr) >= 0) {
            errors.add("checkInDate must be before checkOutDate");
        }
    }

    // Validate amount
    Object amount = response.get("amount");
    if (amount == null) {
        errors.add("amount is required");
    } else if (!(amount instanceof Number) || ((Number) amount).doubleValue() <= 0) {
        errors.add("amount must be a positive number");
    }

    return errors;
}
```
